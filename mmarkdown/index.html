mMarkdown

A fast, clean reader for Markdown files. Open a .md file and read it laid out, with the line numbers of the file next to it.

What it does

  • Opens fast. Double-click a .md file and it is on screen in about a second
  • Laid out at once. Big headings, bold text, lists, tables and code boxes, like Xcode's Markdown view. No preview button to press
  • Line numbers. The numbers on the left are the lines in the file, the same as in your editor
  • Press the lock button (Allow Edit, or Command-E) to change the text right here. Save turns green when there is something to save
  • Or open the file in your own editor, such as CotEditor. mMarkdown shows your changes as soon as you save
  • Light, Dark or the same as your Mac. Choose the text font, the code font and the size
  • Find, print and tabs
  • Free with every feature. Buy me a coffee is an optional tip and unlocks nothing

Common questions

How do I open my .md files with mMarkdown?

Open mMarkdown, go to mMarkdown → Settings → General and press Make Default. Then a double-click on a .md file opens it in mMarkdown. You can also drop a file on mMarkdown in the Dock.

How do I change a file?

Press the lock button at the top of the window, or Command-E. The window shows the text of the file with line numbers. Make your changes and press Save or Command-S. Press the lock again to go back to reading.

Does mMarkdown change my files?

Only when you turn on Allow Edit and save. Reading a file never changes it.

Can I use my own editor?

Yes. Press the arrow button, or Option-Command-E, to open the file in your editor. Choose the editor in Settings → General → Edit with. When you save there, mMarkdown shows the new text straight away.

Why are some lines without a number?

Empty lines in the file have no number on screen. Every other line shows the same number as in your editor.

Why don't I see pictures?

For your privacy, mMarkdown only reads the file you open and loads nothing from the internet. A picture is shown as a small box with its name. Click it to open the picture.

What is Buy me a coffee?

An optional tip to support the app, in mMarkdown → About mMarkdown. It does not unlock anything; every feature is free. Payments and refunds are handled by Apple at reportaproblem.apple.com.

Does mMarkdown collect my data?

No. Your files never leave your Mac. See the Privacy Policy.
