mPath

A path bar for your Finder window. Coming soon to the Mac App Store.

macOS 14 or later

What it does

  • Shows a small address bar on top of your Finder window
  • Click the Finder window title, or press ⌘G, to type a path
  • Suggestions as you type, Tab to fill in
  • Return to go to a folder, ⌘ Return to open a file
  • Type *.pdf to select all matching files
  • ⌘T opens the folder in Terminal
  • No ads and no account
  • Free with every feature. Buy me a coffee is an optional tip and unlocks nothing

How to get started

  1. Get mPath from the Mac App Store.
  2. Open mPath from Applications. On the General tab, allow the three permissions: Accessibility, Control Finder and Folder access (choose Macintosh HD).
  3. Open a Finder window and click its title, or press ⌘G.

Keys

  • ↓ / ↑ move through suggestions
  • Tab fill in a suggestion
  • Return go to the folder or show the file
  • ⌘ Return open the file
  • ⌘↑ parent folder, ⌘H home folder
  • ⌘T open the folder in Terminal
  • Esc close suggestions or leave the bar

Common questions

Why does mPath need these permissions?

Accessibility lets mPath find the Finder window and place the bar on top of it. Controlling Finder lets mPath open the folder you type. Folder access lets mPath suggest folders and files as you type. Everything stays on your Mac.

Accessibility is on, but mPath says it is not allowed

This can happen if you used the older mPath from this website before. Open System Settings › Privacy & Security › Accessibility, select mPath and remove it with the − button. Then open mPath again and allow Accessibility once more.

Where are the settings?

Open mPath from Applications. The General tab shows the permissions, Always show the path bar and Launch at login. Click Apply to save. The About tab has Buy me a coffee and our contact details.

How do I quit mPath?

Open mPath from Applications and click Quit. mPath asks before it quits. Closing the window keeps mPath running.

How do I uninstall it?

Drag mPath from Applications to the Trash. mPath quits by itself. Then remove it from Privacy & Security › Accessibility with the − button.

Does mPath collect my data?

No. See the Privacy Policy.
