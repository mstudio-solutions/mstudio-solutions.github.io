mPath

A path bar for your Finder window. Free for Mac.

Download mPath

Free · macOS 14 or later

What it does

  • Shows a small address bar on top of your Finder window
  • Click the Finder window title, or press ⌘G, to type a path
  • Suggestions as you type, Tab to fill in
  • Return to go to a folder, ⌘ Return to open a file
  • Type *.pdf to select all matching files
  • ⌘T opens the folder in Terminal
  • No Dock or menu bar icon, no ads and no account

How to install

  1. Click Download mPath.
  2. Open mPath-1.0.0.pkg from your Downloads folder and follow the installer.
  3. When mPath starts, allow Accessibility and allow mPath to control Finder when your Mac asks.

Keys

  • ↓ / ↑ move through suggestions
  • Tab fill in a suggestion
  • Return go to the folder or show the file
  • ⌘ Return open the file
  • ⌘↑ parent folder, ⌘H home folder
  • ⌘T open the folder in Terminal
  • Esc close suggestions or leave the bar

Common questions

Why does mPath need Accessibility?

To find the Finder window and place the bar on top of it. Controlling Finder lets mPath open the folder you type.

Where are the settings?

Open mPath from Applications. You can check permissions, always show the path bar and launch at login. Click Apply to save.

How do I quit mPath?

Open mPath from Applications and click the red button. mPath asks before it quits.

How do I uninstall it?

Drag mPath from Applications to the Trash. mPath quits by itself. Then remove it from Privacy & Security › Accessibility with the − button.

Does mPath collect my data?

No. See the Privacy Policy.
