mMarkdown for Windows

A fast, clean reader for Markdown files on your Windows PC. Open a .md file and read it laid out, with the line numbers of the file next to it.

Coming soon to the Microsoft Store.

What it does

  • Opens fast. Double-click a .md file and it is on screen at once
  • Laid out at once. Big headings, bold text, lists, tables and code boxes. No preview button to press
  • Line numbers. The numbers on the left are the lines in the file, the same as in your editor
  • Turn on Allow Edit to change the text right here, then save
  • Or open the file in your own editor. mMarkdown shows your changes as soon as you save
  • Light, Dark or the same as Windows. Choose the text font, the code font and the size
  • Free with every feature. Buy me a coffee is an optional tip and unlocks nothing

Use a Mac? See mMarkdown for Mac.

Common questions

How do I open my .md files with mMarkdown?

In File Explorer, right-click a .md file and choose Open with → Choose another app. Pick mMarkdown and choose Always. Then a double-click on a .md file opens it in mMarkdown.

Does mMarkdown change my files?

Only when you turn on Allow Edit and save. Reading a file never changes it.

Can I use my own editor?

Yes. mMarkdown can open the file in your editor. When you save there, mMarkdown shows the new text straight away.

Why are some lines without a number?

Empty lines in the file have no number on screen. Every other line shows the same number as in your editor.

What is Buy me a coffee?

An optional tip to support the app. It does not unlock anything; every feature is free. Payment is handled by the Microsoft Store.

Does mMarkdown collect my data?

No. Your files never leave your PC. See the Privacy Policy.
