mMarkdown for Windows

A fast, clean reader for Markdown files on your Windows PC. Open a .md file and read it laid out, with the line numbers of the file next to it.

Coming soon to the Microsoft Store. Needs Windows 10 (version 2004) or later, or Windows 11.

What it does

  • Opens fast. Double-click a .md file and it is on screen at once
  • Laid out at once. Big headings, bold text, lists, tables and code boxes. No preview button to press
  • Line numbers. The numbers on the left are the lines in the file, the same as in your editor
  • Press the lock button (Allow Edit, or Ctrl+E) to change the text right here. Save turns green when there is something to save
  • Or open the file in your own editor. mMarkdown shows your changes as soon as you save
  • Light, Dark or the same as Windows. Choose the text font, the code font and the size
  • Find, print and tabs
  • Free with every feature. Buy me a coffee is an optional tip and unlocks nothing

Use a Mac? See mMarkdown for Mac.

Keys

  • Ctrl+E: Allow Edit, or back to reading
  • Ctrl+S: Save
  • Ctrl+Alt+E: Open in your editor
  • Ctrl+F, F3: Find, find next
  • Ctrl+L: Show or hide line numbers
  • Ctrl+Plus, Ctrl+Minus, Ctrl+0: Bigger, smaller or normal text
  • Ctrl+N, Ctrl+O: New file, open a file
  • Ctrl+W, Ctrl+Tab: Close tab, next tab
  • Ctrl+P: Print
  • Ctrl+, (comma): Settings
  • Ctrl+Shift+R: Show in File Explorer

Common questions

Where are Settings and About?

Press the ⋯ button at the top right of the window. Settings and About mMarkdown are at the bottom of the list. Windows has no menu bar at the top of the screen, so everything else you would find in a menu is in this list too.

How do I open my .md files with mMarkdown?

In File Explorer, right-click any .md file and choose Open with → Choose another app. Pick mMarkdown and choose Always. Or in mMarkdown press ⋯ → Settings → Make Default…, which opens the Windows Default apps page. Windows does not let an app make itself the default, so you choose it there.

How do I change a file?

Press the lock button at the top of the window, or Ctrl+E. The window shows the text of the file with line numbers. Make your changes and press Save or Ctrl+S. Press the lock again to go back to reading.

Does mMarkdown change my files?

Only when you turn on Allow Edit and save. Reading a file never changes it.

Can I use my own editor?

Yes. Press the arrow button, or Ctrl+Alt+E, to open the file in your editor. Choose the editor in Settings → General → Edit with. If you have not chosen one, mMarkdown uses Visual Studio Code, Notepad++ or Notepad. When you save there, mMarkdown shows the new text straight away.

Why are some lines without a number?

Empty lines in the file have no number on screen. Every other line shows the same number as in your editor.

Why don't I see pictures?

For your privacy, mMarkdown only reads the file you open and loads nothing from the internet. A picture is shown as a small box with its name. Click it to open the picture.

Where are my tabs?

New files open as tabs in the same window. The tabs are in the title bar, like Notepad. Ctrl+W closes a tab and Ctrl+Tab goes to the next one.

What is Buy me a coffee?

An optional tip to support the app, in ⋯ → About mMarkdown. You can buy 1 to 5 coffees. It does not unlock anything; every feature is free. Payments and refunds are handled by Microsoft: see Order history at account.microsoft.com.

When I press Esc in the find box, the find bar stays open. Why?

If Windows shows word suggestions while you type, the first Esc closes the suggestions and the second closes the find bar. You can turn the suggestions off in Windows Settings → Time & language → Typing.

Does mMarkdown collect my data?

No. Your files never leave your PC. See the Privacy Policy.
