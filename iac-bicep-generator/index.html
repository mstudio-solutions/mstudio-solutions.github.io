IaC Generator for Bicep

Build Azure infrastructure by drag and drop. Free, in your browser.

Open the tool

Free · Works in your browser · No sign-up

What it does

  • Drag Azure resources onto a canvas and link them
  • Edit settings on the side panel
  • Get ready-to-deploy Bicep code. Copy it or download the file.

Resources you can use

  • Foundation: Resource Group, Virtual Network, Subnet, Network Security Group
  • Compute: Virtual Machine, App Service Plan, App Service, Function App, Container Registry
  • Data and storage: Storage Account with blob containers, SQL Server and Database, MySQL and PostgreSQL Flexible Server

How to use it

  1. Open the tool.
  2. Drag resources from the left onto the canvas.
  3. Click a resource to change its settings.
  4. Drag the dots to link resources, for example VM to Subnet to VNet.
  5. Copy the code or download the Bicep file.

Private by design

Everything runs in your browser. Nothing you build is sent to us or saved on a server.
